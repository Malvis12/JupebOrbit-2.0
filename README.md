# JupebOrbit-2.0

JUPEB Orbit is a specialized Computer-Based Testing (CBT) prep platform designed for Joint Universities Preliminary Examinations Board (JUPEB) candidates.

## Features
- **Authentic CBT Simulator:** 1-hour Single-Subject & 3-hour Marathon mock exams with voice audio proctoring.
- **Official 16-Point Grading Engine:** Exact grade-to-point conversions ($A=5 \dots F=0$) and official JUPEB +1 bonus point calculation.
- **Active Recall Studio (Flash-Master):** Multi-interval Leitner Spaced Repetition (SRS) targeting weakness concepts with self-derivation scratchpads.
- **Adaptive Daily Breakfast Mix:** Daily multi-subject micro-quiz with 60s Speed Drill blitz mode.
- **Formula Vault:** Interactive KaTeX LaTeX formula reference drawer.
- **Admin Ingestion Studio:** Gemini AI PDF past question extraction with deterministic ID generation.
